# Ultralight Tags Developer Docs

This site is the browser entry point for understanding and navigating the code.
It is separate from the end-user manuals under `host/docs`, which are packaged
with the host tools.

Use this portal for:

- architecture and design notes;
- source-adjacent module READMEs;
- firmware and host subsystem maps;
- Doxygen API reference generated from project-owned source comments.

The Markdown pages shown here are staged from their source locations during the
build. Edit the original files in the repository, not the generated build tree.
