# Firmware

Firmware documentation is organized around the embedded source tree:

- `embedded/boards`: board pin, clock, and build ownership;
- `embedded/tags`: tag firmware targets and shared runtime behavior;
- `embedded/tags/common`: reusable firmware modules;
- `embedded/tags/families`: family-level device and data-log implementations.
