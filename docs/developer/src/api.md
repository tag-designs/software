# API Reference

The developer docs build places Doxygen output under `api/` when Doxygen is
available:

[Open the Doxygen API reference](api/index.md)

API reference complements the design notes: use Doxygen for symbol contracts and
use Markdown design documents for architecture, rationale, and workflows.
