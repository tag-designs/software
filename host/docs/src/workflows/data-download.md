# Data Download

Use this page for retrieving logged data from a tag.

## Download Data

1. Connect the tag or base station.
2. Open [Tag Monitor](../apps/tagmonitor.md), or use
   [tag-dwnld](../cli/tag-dwnld.md) from a terminal.
3. Choose the output location.
4. Start the download.
5. Confirm that the output file was created.

Link to the relevant visualizer:
